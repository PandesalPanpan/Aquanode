# AquaNode logo

The mark is a water drop (the tank) with a fish inside and a two-leaf sprout (the plants) growing from its tip: fish, water and plants together, which is what aquaponics is.

| File | Use it for |
|---|---|
| `aquanode-logo-on-dark.svg` / `.png` | Full logo on dark backgrounds (the Dashboard, dark slides, video titles) |
| `aquanode-logo-on-light.svg` / `.png` | Full logo on white or light backgrounds (reports, posters) |
| `aquanode-mark.svg` / `aquanode-mark-1024.png` | The symbol alone (avatars, stickers, small spaces) |

The SVGs carry their font (Bricolage Grotesque Bold, SIL Open Font License), so they look the same anywhere. PNGs have transparent backgrounds.

Colors: water `#6fc3c9` · leaf `#7fb069` and `#9ccc7f` · dark `#18211f` · light text `#eef3ea`.

The app icons, the browser-tab icon and the Dashboard header are made from `aquanode-mark.svg`. After changing it, run `node tools/make-icons.mjs` and update the copy in `Logo()` in `web/src/App.jsx`.
